# sl0tbot-pub

Public help page for **sl0tbot**, a Twitch chat bot for slot picking and stats.

Live at **https://rakizi.github.io/sl0tbot-pub/**

## What's in here

`index.html` — a single self-contained page. No build step, no dependencies, no
external CSS/JS/fonts. Edit it and push; GitHub Pages serves it directly.

## What's deliberately not in here

The bot's source and configuration live in a private repository. Nothing in this repo
reads or contains tokens, credentials, or channel configuration — it is documentation
only, kept separate so the page can be public without the bot being public.
