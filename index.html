Slot picker, slot stats, and giveaway-winner lookups for Twitch chat. Type a command in any channel where the bot is present.

Start here

Typing !random help in chat won't get you a reply — the bot doesn't answer help requests. Everything it can do is on this page.

Commands

What you can type

Every command works the same way in each channel that has it. Where a cooldown is listed, it applies per person, per channel.

!random [filters]

10s cooldown

Picks one slot at random from the catalogue. Add filters to narrow what it can pick — provider, volatility, max win, RTP, gameplay traits, themes. Filters combine in any order.

!random
Pick from the channel's default pool
!random hacksaw cluster
Narrow by provider and gameplay trait
!random default <filters>
Save filters as your personal default
!random default show
See what you have saved
!random default reset
Clear your saved filters

!slotinfo <name>

10s cooldown

Stats for one slot — RTP, max win, volatility, provider, release year. If the name matches several slots you get a numbered list, then pick from it. The longer forms below — paytable, desc and detailed — carry a 40 second cooldown instead of 10.

!slotinfo sweet bonanza
Summary stats
!slotinfo paytable <name>
Symbol paytable
!slotinfo desc <name>
Game description
!slotinfo detailed <name>
Everything at once
!slotinfo pick <n>
Choose from an ambiguous match list

!same5 [@user] [detailed]

15s cooldown

Same5Winners stats for this channel's tracked giveaway winner. Repeating the same lookup is deduped for about 15 seconds, or 60 seconds for the detailed form.

!same5
The channel's current tracked winner
!same5 @user
Someone specific
!same5 detailed
Per-streamer breakdown

!whocalled <slot>

10s cooldown

Who called that slot first in the current run, how long ago, and anyone else who called it inside the credit window. Repeat calls by the same person count once. Earlier runs are reported separately so an old call is never mistaken for a fresh one.

!whocalled pirots
First caller in this run
!whocalledit pirots
Same command, alternative spelling

Filters

Narrowing !random

Filters are plain words typed after the command, in any order. Anything you leave out stays at the channel default.

Provider & format

Name any provider, or ask for a format.

Volatility

A word or a numeric range, 1 to 7.

highlow3-5low-high

Release year

Catalogue covers 2015 to 2026.

20202015-2026

Max win

Exact, a floor, a ceiling, or a band. k works as thousands.

25000x7500x+7500x- -7500x7500-25000x300k

Rainbet stats

Every one takes + for a floor, - for a ceiling, or a band.

Strictness

Whether a slot missing catalogue data can still be picked.

Availability

Where it works

Every command works in every channel below — what changes is who may use it. Open channels answer anyone. Restricted channels answer moderators, the broadcaster, and bot operators only, until the streamer or their mods are happy to open them to chat.

All four commands follow the same access rule in each channel.

Cooldowns are per person, per channel. A command on cooldown is ignored rather than refused, so nothing appears in chat — wait a moment and try again.

Slot data comes from the Rainbet catalogue. A slot that isn't in it can't be picked or looked up.
